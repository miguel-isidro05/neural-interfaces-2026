# NeuralBench Integration

Minimal compatibility layer between selected local models and the official NeuralBench / NeuralTrain workflow.

## What belongs here

- NeuralTrain-compatible model wrappers
- NeuralBench YAML model configs
- Minimal overrides

## Do not put here

- Full NeuralBench repository
- Raw local experiments
- Codabench packages

## Codex guidance

Only promote models here once they are worth validating with the official benchmark.
