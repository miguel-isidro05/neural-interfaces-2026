# Neural Interfaces Challenge 2026

Repository for Track 2 and Track 3.

## Main separation

- `local/`: local research, training, evaluation, experiments, notebooks and outputs.
- `neuralbench_integration/`: only the minimum compatibility layer needed to run selected models with NeuralBench / NeuralTrain.
- `submissions/`: final Codabench packages and submission history.
- `docs/`: GitHub Pages / public documentation.

NeuralBench and NeuralTrain are external tools. Do not copy their full repositories here unless explicitly creating a fork.
